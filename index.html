Menú Dinámico

Menú generado utilizando JSON, HTML, CSS y JavaScript

Bienvenido

Este proyecto demuestra cómo crear un menú dinámico utilizando una estructura de datos JSON. Las opciones pueden agregarse, modificarse o eliminarse sin cambiar directamente el código.

Información del proyecto

El menú utiliza JSON para almacenar las opciones y JavaScript para generar dinámicamente la interfaz. Los cambios realizados se almacenan en el navegador mediante localStorage.
